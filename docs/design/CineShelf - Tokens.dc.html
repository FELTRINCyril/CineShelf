Étape 8 · Les tokens · direction 2a Plein cadre

Les valeurs, une seule fois, pour que le code n'en invente aucune

Tout ce qui est écrit ici est la source unique : les écrans des étapes 1 à 7 n'utilisent rien d'autre. La valeur canonique est l'oklch — le hex est donné pour référence et pour les catalogues d'assets. Les rapports de contraste sont mesurés (WCAG 2.1) contre le fond de leur propre apparence ; le seuil retenu est AA 4,5:1 pour tout texte, y compris le texte secondaire et tertiaire, et 3:1 pour les traits et icônes non textuels.
